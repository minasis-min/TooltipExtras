# 検証方法

Windowsの対応SDKを用意し、[ビルド手順](DEPENDENCIES.md)に従って `scripts/Build.ps1` を実行します。Releaseビルド、自動チェック、Dev用ファイルの配置を行います。通常のDevビルドではZIPを作成しません。配布ZIPを準備する場合だけ `scripts/Build.ps1 -Package` を明示します。

自動チェックは、文字列の分離・復元、設定の保存・移行、互換性判定、レイアウト計算、再接続時の例外処理などを対象にします。ネイティブ関数を必要とするゲーム内の描画や実FPSを再現するものではありません。

ゲーム内では、アイテム切替、HQ／通常品質の切替、価格の遅延更新、各機能のON／OFF、無効化・再読み込みを確認します。Dev版と配布版のインストール・更新は別に確認してください。

Frameworkスレッド上で `TooltipExtras.RelayStatus.v1`（引数なし、戻り値string）のIPCを呼ぶと、DR分離の状態・失敗理由・件数・直近の説明欄の高さをJSONで取得できます。本文、アイテムID、キャラクター名、チャット、スクリーンショットは返さず、設定も変更しません。これらの数値と画面上の表示を照合して確認してください。

録画時の条件は [USAGE.md](USAGE.md) を参照してください。
