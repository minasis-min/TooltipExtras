# 設定・併用条件

## 表示

`/tooltipextras` から基本・表示・有効・診断を開きます。設定は自動保存されます。対応済みプラグインは初期ONです。新しく追加された有効設定も既定ONとなり、保存済みのON/OFF設定は保持します。引用元名は表示を切り替えられます。「有効」は使用設定であり、現在の対象で分離が成立した保証ではありません。診断で対応DLLの検出と処理状態・拒否理由を確認してください。

| 情報 | 条件 |
|---|---|
| 価格 | 対応する価格表示プラグインのDLLと確認済みノード形状。初期ON |
| 収納・衣装セット | 対応する収納情報プラグインの3つの公開IPCが登録され正常応答すること |
| 追加販売価格 | 対応する販売情報プラグインのDLL。分離の実機確認待ち |
| 追加パッチ | 内蔵固定データ。外部プラグインの更新では更新されません |

外部プラグインが元ツールチップへ追加するパッチ情報は自動除去しません。重複する場合は元プラグインの該当表示を停止してください。協調版を併用しTEのパッチ表示をOFFにすると、次回更新時にIPCを拒否し元プラグインの表示へ戻します。

パッチ表示の対象アクションはマウント・ミニオン等で、すべての戦闘アクションを対象としません。収納判定がfalseの場合、未登録と情報未読込は区別できません。すべての追加情報の分離には対応していません。

## 保存と旧設定

配布版はDalamudが指定するプラグイン設定フォルダを使い、Dドライブを要求しません。DLLの配置はDalamudが管理します。

新設定がなく、DLLの隣に旧 `data/settings.json` が残る場合は旧設定を読み込み、新しい設定フォルダへ保存します。旧ファイルは変更しません。DLL配置が変わる場合は、旧 `settings.json` を診断画面で示す新設定先へ手動コピーしてください。読み込みに失敗した設定は既定値で上書きしません。

アンインストール後、設定・診断も削除したい場合は保存先を確認し、このプラグインのファイルだけを削除してください。診断には環境・識別情報が含まれるため、公開前に内容を確認し必要部分だけ共有してください。

## 録画と未確認範囲

ImGuiを録画から除外する機能が有効に働いていない場合、専用パネルも録画に映ります。未分離の情報はゲーム画面とともに録画されます。初回表示・非同期更新のフレーム単位の録画除外は未確認です。

実機確認と自動チェックの範囲は [TESTING.md](TESTING.md)、正確なDLL識別と依存は [DEPENDENCIES.md](DEPENDENCIES.md) を参照してください。
