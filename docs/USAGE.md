# 設定・併用条件

## 表示

`/tooltipextras` から基本・表示・有効・診断を開きます。設定は自動保存されます。対応済みプラグインは初期ONです。新しく追加された有効設定も既定ONとなり、保存済みのON/OFF設定は保持します。引用元名は表示を切り替えられます。「有効」は使用設定であり、現在の対象で分離が成立した保証ではありません。Debug / 診断で機能ごとの互換性・処理状態・拒否理由を確認してください。

| 情報 | 条件 |
|---|---|
| 価格 | 価格処理とネイティブ構造の互換性、対象ノード形状を確認。初期ON |
| 収納・衣装セット | 対応する収納情報プラグインの3つの公開IPCが登録され正常応答すること |
| 追加販売価格 | 販売処理とコールバック境界の互換性を確認 |
| 商店・マーケット・分解・ID情報 | 元の表示機能もONにします。TE専用の出力がOFFの場合、本文の境界を確認できない欄は元ツールチップに残します |
| 追加パッチ | 内蔵固定データ。外部プラグインの更新では更新されません |

## TE専用の出力

「基本」→「対応する追加情報をTEだけに表示」は既定ONです。対応する追加情報は元ツールチップへ追加せず、TEで表示します。取得・パネル表示に失敗した情報を元ツールチップへ戻すことはありません。同じ種類の失敗は、TEを読み込んでいる間に一度だけゲーム内チャットへ通知します。MaskedDalamudなどのチャット非表示設定によって通知も隠れる場合があります。

対象はDRの商店・市場・分解・IDの文字情報、ATの所持数・保管場所・入手先・用途と見出し・余白、Item Vendor Locationの販売情報、Simple Tweaksの対応する文字情報です。元の機能も有効にしてください。接続後に対応していない表示処理や生成形式が見つかった場合は、追記を保留します。

Price Insightと画像は従来の分離方法を使います。これらや未対応のプラグインについて、追加表示が残らないことを保証する設定ではありません。接続・互換性の確認自体が成立しなかった場合も、元プラグインの表示が残る可能性があります。Debug / 診断で状態を確認してください。

この設定をOFFにすると、対応機能も従来の分離方法へ戻ります。TEや対象プラグインの対応設定を無効にした場合、TEを解除した場合には、元プラグインの表示へ戻ります。MaskedDalamudのON/OFFとは連動せず、手元のTEパネルはそのまま使用します。

外部プラグインが元ツールチップへ追加するパッチ情報は自動除去しません。重複する場合は元プラグインの該当表示を停止してください。協調版を併用しTEのパッチ表示をOFFにすると、次回更新時にIPCを拒否し元プラグインの表示へ戻します。

パッチ表示の対象アクションはマウント・ミニオン等で、すべての戦闘アクションを対象としません。収納判定がfalseの場合、未登録と情報未読込は区別できません。すべての追加情報の分離には対応していません。

## 保存と旧設定

配布版はDalamudが指定するプラグイン設定フォルダを使い、Dドライブを要求しません。DLLの配置はDalamudが管理します。

新設定がなく、DLLの隣に旧 `data/settings.json` が残る場合は旧設定を読み込み、新しい設定フォルダへ保存します。旧ファイルは変更しません。DLL配置が変わる場合は、旧 `settings.json` を診断画面で示す新設定先へ手動コピーしてください。読み込みに失敗した設定は既定値で上書きしません。

アンインストール後、設定・診断も削除したい場合は保存先を確認し、このプラグインのファイルだけを削除してください。診断には環境・識別情報が含まれるため、公開前に内容を確認し必要部分だけ共有してください。

## 録画と未確認範囲

ImGuiを録画から除外する機能が有効に働いていない場合、専用パネルも録画に映ります。未分離の情報はゲーム画面とともに録画されます。初回表示・非同期更新のフレーム単位の録画除外は未確認です。

実機確認と自動チェックの範囲は [TESTING.md](TESTING.md)、正確なDLL識別と依存は [DEPENDENCIES.md](DEPENDENCIES.md) を参照してください。

## 追加情報の中継

所持数・保管場所・入手先・用途の表示を中継する場合は、元の表示項目もONにしてください。元のプラグインが作った追加分だけをパネルへ移します。表示項目の選別・名前・順序・色は元の設定を使います。TE側の「有効」で切り替えられます。

TE専用の出力がONの場合、ATの箱の内容・リスト・市場価格・開放状況・衣装セット・素材のパッチ情報・保管場所の追加表示も、対応する元の生成処理からTEへ移します。互換性や出力形式を確認できない項目は追記を保留します。OFFの場合は従来の対応範囲を使用し、分離できない追記を元ツールチップへ残します。

## 表示する情報の選択

「有効」→「表示する情報」で、食事・薬品、マテリア能力値、分解、収集品報酬、ロゴス情報、譜面・ランダム報酬・衣装セットの取得状況、アンロック画像、絵画画像を個別に選択できます。元の追加機能もONにしてください。

マテリアの合計・増分をTEへ表示できます。標準のマテリア名・空きスロット欄は元ツールチップに残ります。

プレビュー分離時は元の画像を非表示にし、専用パネルへ表示します。配置の確定を待つ間、元ツールチップ全体を最大100ms非表示にする場合があります。配置や画像の取得に失敗した場合の状態・理由はDebug / 診断で確認できます。

「アイテム名・ミラプリ名」を有効にすると、元機能が生成した2行の名前をTEへ表示します。元ツールチップの名前欄はゲーム標準の表示になります。元機能は有効のまま使用してください。

TE専用の出力がONの場合、Simple Tweaksの「アイテム名・ミラプリ名」は現在の名前データからTEへ表示し、元ツールチップへ追加の名前欄を作りません。アイテムIDも元のカテゴリ欄へ書き込む前にTEへ転送します。「アイテム操作のヒント」はTE側で表示を切り替えられ、元のショートカット操作は引き続き使用できます。

診断の収集は通常利用ではOFFを推奨します。不具合の調査時に有効にし、再現後に診断を保存してください。

「Debug / 診断」→「分離できなかった文字列」を開き、「未分離の文字列を記録」をONにしてから再現すると、取得済みの未分離文字列と理由を確認できます。直近20件、各1024文字まで記録し、同じ内容は発生回数にまとめます。文字列の生成前に処理を止めた場合は、理由だけを表示します。記録をOFFにするかTEを再ロードすると履歴を消去します。

「診断を保存」で、この履歴も診断JSONに含めます。元の欄全体やツールチップ内の名前などを含む場合があるため、共有前に内容を確認してください。保存済みのTE診断JSONは直近10ファイルを保持し、新しい保存の成功後に古いものを削除します。「記録を消去」や記録OFFは、保存済みJSONを削除しません。
